# Nimbus-2001

Nimbus-2001 is an experimental rocket project I have been working on to learn and build across different parts of rocketry from CAD and structural design to simulations, ground testing, telemetry and software.

This repository is basically the engineering archive of the project. I am keeping the designs, simulations, reports, test data and software together so that the development of the rocket can be followed from the early designs to testing.

> This is an experimental/student engineering project. Files in this repository may change as the design is tested and improved.

### Structural Simulation

Structural simulations were performed to understand how different components behave under expected loads.

The analysis includes things such as:

- Von Mises stress
- Principal stresses
- Total displacement
- Safety factor
- Load distribution

I used these results mainly to find weak areas in the designs and decide what needed to be changed before making physical parts.

### CFD / Aerodynamics

I also worked on external-flow CFD simulations of the rocket.

The CFD work includes velocity contours, vector plots and streamlines to study airflow around the body and fins and to visualize the wake behind the rocket.

This part is still being improved as I learn more about CFD and validate the simulation setup.

## ASTRA Mission Control

ASTRA is the ground-side software I built for telemetry monitoring and analysis.

Ground Systems Node GS-01 is a desktop-first telemetry monitoring, replay, inspection and session-recording interface for engineering sensor data.

### Run

    npm install
    npm start

Open `http://localhost:3000`.

### Capabilities

- Synthetic telemetry simulation with anomaly injection
- Node.js/Express telemetry ingestion
- Socket.IO data broadcast
- Live telemetry charts
- Raw packet inspection
- Mission events
- Session recording
- CSV replay
- System-health monitoring
- SIM / REPLAY / LIVE source modes

The idea is to eventually have one interface where I can watch the important vehicle data during ground testing and then replay the same data later for analysis.

## Why this repository exists

I didn't want Nimbus-2001 to end up as just a final CAD file or a few photos.

I wanted to keep the actual engineering trail — designs that changed, simulations, reports, software, test records and things that didn't work.

So this repository will keep changing as Nimbus-2001 develops.
