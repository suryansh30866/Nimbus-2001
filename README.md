# ASTRA Mission Control

Ground Systems Node GS-01 is a desktop-first telemetry monitoring, replay, inspection, and session recording interface for engineering sensor data.

## Run

```powershell
npm install
npm start
```

Open `http://localhost:3000`.

## Capabilities

- Synthetic telemetry simulator with anomaly injection.
- Node.js/Express ingestion, validation, sequence inspection, deterministic event rules, session recording, and Socket.IO broadcast.
- Dynamic frontend channel discovery, live charts, raw packet inspection, channel detail, packet transport health, mission events, replay, session archive, system health, and big board mode.
- CSV loading and timing-preserving replay with pause, seek, and speed controls.
- Source mode is always visible: `SIM`, `REPLAY`, or `LIVE`.

## Data Philosophy

The UI reports transport and data behavior. It does not infer physical causes. Events such as rapid value changes, sequence gaps, flatlines, and invalid samples are generated by deterministic rules documented in the System screen and `docs/detection-rules.md`.
